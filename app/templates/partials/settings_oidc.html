OIDC client checklist

Works with any OpenID Connect provider (Keycloak, Authentik, Okta, Azure AD, etc.).

  • Client type: confidential (client secret), authorization code flow enabled
  • Redirect / callback URI: {% if oidc_redirect_uri %} {{ oidc_redirect_uri }} {% else %} https://<server-url>/login/oidc/callback - set Server URL under General to fill this in {% endif %}
  • Allowed web / CORS origin: the same host as the server URL (or your IdP’s equivalent of “+” / allow all for that origin)
  • Scopes: at least openid and email (required for account identity)
  • ID token (or userinfo) should include the configured username and groups claims
  • Optional: map IdP groups into a list claim named as in “Groups claim” (default groups)
