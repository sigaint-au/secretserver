Server URL

Public base URL of this application (no trailing slash). Used for OIDC redirect URIs and ESO / External Secrets Operator YAML defaults.

Login banner

Add the required disclosure notice and an optional link to your system-use policy.

Reveal & clipboard

Clipboard auto-clear and reveal auto-hide are per-device defaults; the scope of an approved reveal grant is server-wide.

Account registration

Control whether new local accounts can be created at /register. Existing users and LDAP login are unaffected.

Team creation

When disabled, only global admins can create teams. Existing teams are unchanged.

Two-factor authentication

Any user can enable TOTP. When enforced below, global admins must enroll and cannot disable 2FA.

Token expiry policy

Set expiry requirements for newly issued personal access and machine tokens.

Maximum lifetime is measured in days and applies when an expiry is required. Lifetime fields are enabled only while the matching expiry requirement is on.

Personal access tokens

Prevent personal tokens from remaining valid indefinitely.

Machine tokens

Limit service credentials to a defined lifetime.
